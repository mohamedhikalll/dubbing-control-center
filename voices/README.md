# Voice references / ملفات الصوت المرجعية

Do not commit private or third-party voice recordings. Place your own authorized reference WAV files here locally; recommended clear speech, mono, 24 or 44.1 kHz. This folder is intentionally empty in the public repository.

لا ترفع تسجيلات صوتية خاصة أو لأشخاص آخرين. ضع هنا محليًا ملفات WAV تملك حق استخدامها كمرجع صوتي. هذا المجلد فارغ عمدًا في المستودع العام.
